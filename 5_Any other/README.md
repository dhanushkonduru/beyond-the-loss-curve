Supporting material that doesn't fit the other five categories: the measured results behind every number in the manuscript, and the manuscript's markdown source.

## `paper_source/`

`paper_full.md` — the markdown source the manuscript was originally built from.

> **Warning — do not rebuild over the delivered manuscript.** After it was generated, the `.docx` was edited by hand in Word: the three author biographies, the author photographs and their text wrapping, and the table borders. None of that exists in `paper_full.md`, so regenerating from this file produces a document that is missing all of it. Rebuild only to a *new* filename, and treat the delivered `.docx` as the authoritative copy. To change a figure in the delivered file, swap the image inside the `.docx` package (`word/media/imageN.png`, numbered in figure order) rather than rebuilding.

For reference, the original build was:

```bash
pandoc paper_full.md -o paper_raw.docx --reference-doc="<IEEE Access template>.docx"
python apply_template_format.py paper_raw.docx Beyond_the_Loss_Curve_Manuscript.docx
```

(`apply_template_format.py` is in [`../2_Source code/paper_figures/`](../2_Source%20code/paper_figures/).)
